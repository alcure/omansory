# Contributing / Contribuição

## English

Issues and pull requests are welcome in **English or Portuguese**. Keep the Hyprland Lua layout compatible with 0.55+ (`hl.layout.register`, `target:place`). Do not edit `/usr/share/omarchy/`. Installer changes must keep the `-- BEGIN omansory` / `-- END omansory` fences so user config stays reversible.

## Português

Issues e pull requests são bem-vindos em **inglês ou português**. Mantenha o layout Lua compatível com Hyprland 0.55+ (`hl.layout.register`, `target:place`). Não edite `/usr/share/omarchy/`. Mudanças no instalador devem preservar as cercas `-- BEGIN omansory` / `-- END omansory` para o config do usuário continuar reversível.
